Control UC-04 — S3 Encryption at Rest

One evidence pull, graded three ways

A single read-only check against each S3 bucket produces one evidence record. That record is never re-collected — it's simply graded against SOC 2, ISO 27001, and NIST 800-53's different pass bars.

03 Exception register — the WAIVED case

WAIVED is not a pass. It means the bucket fails the technical check but has an approved, documented reason — so it's tracked here instead of counted as a failure. This is the record an auditor asks to see for any waived item.

04 Finding worth knowing

AWS default encryption, since Jan 2023

Every S3 bucket gets SSE-S3 applied automatically and it cannot be turned off — even baseline-default-only, which has zero encryption configuration in Terraform, still reports as encrypted.

SOC 2 and ISO's "no encryption present" fail case is now unreachable in live AWS. NIST SC-28(1)'s customer-managed-key requirement is the only bar left that still demands deliberate action rather than relying on the provider's floor.
